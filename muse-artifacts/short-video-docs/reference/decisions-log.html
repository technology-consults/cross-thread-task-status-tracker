2026-09-24 — Stale-content policy

  • Nothing is ever deleted. Unlist only when content is fully outdated AND misleading/inaccurate.
  • Tech evolved but video still broadly fine → keep public with redirect strategies (updated caption/description, pinned comment, cards/end screens pointing to newer version).
  • Slightly stale → in-place update; one stale long-form segment → trim where supported + redirect; thoroughly outdated → full remake as a new upload, hide/unlist the old only if leaving it public would mislead.
  • Review runs monthly; actions are gated by the sponsor obligations ledger (no unlist before minimum-live dates).
  • Keep comments enabled rather than hiding feedback.

2026-09-24 — Sponsor/affiliate stances

  • Build order: affiliate infrastructure first (day-1, zero-audience lever), media kit + outbound next, sponsorships after audience proof. Sponsorships are ~0% of revenue for the first 6–12 months.
  • Five sponsorship routes: inbound discovery, personalized outbound pitching, creator marketplaces, agencies/MCNs, UGC/content-production deals.
  • Proposed capabilities: auto-generated media kit from real metrics, sponsor prospect shortlist, outreach templates + tracking, rate-card framework, sponsor/deal obligations ledger, affiliate-program research + applications, link hub + tracked links, CTA rotation, revenue attribution/reporting.
  • Manual gates: identity/tax details, applications, outreach, negotiation, closing.

2026-09-24 — Review gates and automation rules

  • Keep publishing and promotion plans, specs, and task lists separate. One owner per task: Balram (decisions, manual work, approvals), Muse (technical work).
  • Work one task at a time in dependency order. Present each result; BalRam replies "adjust" or "done." No task is checked off and no dependent work starts until "done."
  • State upfront and recurring costs on every proposal. Preserve 🟢/🟡/🔴/🟠 automation indicators.
  • Pilot publishing stays behind per-video approval. Full automation begins only after "go auto," "lock the vision," or equivalent.
  • "Turn review back on" restores review. "Pause all publishing now" halts everything until BalRam says resume.
  • Cadence adjustable by one prompt for a day, week, month, or indefinitely.
